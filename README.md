# Heavenly Dao Chronicles
### The Ultimate Battle Through The Heavens Inspired AI Universe Creator

**Version:** V9 Prototype — Fully Interactive Frontend

---

## What This Is

A complete, self-contained web application that brings the core vision of the HEAVENLY DAO CHRONICLES specification to life as a working prototype.

You can:

- Create entire BTTH-style cultivation worlds
- Generate detailed characters with Dou Qi ranks, bloodlines, physiques, secrets
- Train and attempt breakthroughs in the Cultivation Simulator
- Discover Heavenly Flames
- Generate techniques (Huang → Tian Rank)
- Create magical beasts
- Manage / view the Eight Ancient Clans & Supreme Beast Clans
- Found your own sect
- Simulate battles with AI-style explanations
- Generate story chapters that remember your world & characters
- Save everything to browser localStorage
- Export your world as JSON

## How to Run

### Option 1 — Local
1. Download the entire `heavenly-dao-chronicles` folder
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)

No server required. Everything runs client-side.

### Option 2 — Deploy
Upload the folder to:
- Netlify (drag & drop)
- Vercel
- GitHub Pages
- Cloudflare Pages
- Any static host
